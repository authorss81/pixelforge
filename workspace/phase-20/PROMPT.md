# phase-20 - Live preview that updates while you drag the sliders

**Roadmap:** P3.1  
**Depends on:** nothing

## Goal

Moving any slider or typing any dimension updates the preview immediately, without pressing Process.

## Why it matters

This is the single largest perceived-quality jump available. Right now the app gives no feedback at all until you commit, so tuning a size is guesswork. It is why the app feels like a form rather than a tool.

## Files

Touching anything outside this list needs a justification in your notes.

- `lib/ui/widgets/settings_view.dart`
- `lib/ui/widgets/preview.dart`
- `lib/ui/home_page.dart`
- `lib/core/engine.dart`
- `test/resize_test.dart`

## Approach

1. Add a `renderPreview` entry point that reuses the real pipeline on a downscaled proxy, not an approximation. A preview that lies is worse than no preview.
2. Debounce at roughly 120ms and coalesce. A slider drag fires continuously and must not queue work.
3. Drop stale previews. If a new request arrives while one is in flight, discard the older result rather than rendering it.
4. Run the preview on a capped-size proxy, for example longest edge 900px, so interaction stays smooth.
5. Show the computed output dimensions live next to the preview, since that is what the user is actually trying to hit.
6. The before/after comparison must stay honest. Show the proxy at the target aspect ratio, not a stretched approximation.

## Acceptance criteria

Each must be checkable by a test or by `flutter analyze`.

- [ ] Dragging the quality slider updates the preview without pressing Process
- [ ] Preview work is debounced and stale results are discarded. A test proves a slow render does not overwrite a newer one
- [ ] The preview is generated by the real pipeline, not a separate code path
- [ ] Interaction stays responsive while a preview renders
- [ ] The displayed output dimensions always match what Process would produce
- [ ] A new test in `test/` fails before this change and passes after
- [ ] `flutter analyze` reports `No issues found!`
- [ ] `dart format --output=none --set-exit-if-changed lib test` is a no-op
- [ ] `flutter test` reports `All tests passed!`
- [ ] `test/privacy_test.dart` is unmodified

## Regression risk

A full pipeline render on every slider tick will melt the UI unless it is on the proxy and debounced. Do both.

## Out of scope

GPU shaders for live preview, and canvas-level editing.
